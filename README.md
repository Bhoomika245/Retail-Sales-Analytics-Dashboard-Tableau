# Retail Sales Analytics Dashboard (Tableau)
## Project Overview
This project is an interactive Retail Sales Analytics Dashboard built using Tableau to analyze sales performance, customer behavior, product performance, payment methods, and branch-wise trends through interactive visualizations.
## Tech Stack
- Tableau
- Data Visualization
- Dashboard Design
- Data Analysis
## Features
- Interactive KPI Cards
- Sales Performance Analysis
- Product Line Analysis
- Customer Type Analysis
- Payment Method Analysis
- Branch-wise Sales Analysis
- Interactive Filters and Slicers
## Key Insights
- Identified top-performing product categories.
- Compared sales across different branches.
- Analyzed customer purchasing patterns.
- Visualized payment method distribution and sales trends.
